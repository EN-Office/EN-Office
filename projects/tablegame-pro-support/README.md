# テーブルゲームプロ支援プログラム (TGP) — プロジェクト憲章

## 目的
麻雀・将棋・囲碁・ポーカー等のテーブルゲームのプロ/準プロが、**大会賞金以外**で生計を立て、プロ活動を継続できるようにする支援プログラムを設計する。

## 支援方針（初期候補・いずれも可）
- 事務所（マネジメント会社）を設立してプロを所属させる
- 配信チャネルを作り収益化する
- ファンクラブ化する
- グッズを販売する
- その他、上記の組み合わせや新規案
