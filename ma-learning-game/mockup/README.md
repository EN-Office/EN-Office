# mockup

ブラウザで動くチュートリアル体験モックアップ（ADR-0002、ADR-0003）。`index.html` をブラウザで開くだけで動く（ビルド不要。外部への通信は Google Fonts のみ）。VS Code からローカルアプリとして起動する方法は [app/README.md](../app/README.md)。

見た目と操作の規則は [UIガイドライン](../docs/03_spec/ui-guidelines.md) に従う。

- 画面比率：縦16:横9のスマホ縦画面を想定し、ブラウザ中央に 9:16 のステージを表示する。
- 目次（index）から、ボタンで各コンテンツを体験できる。URL の `#opening` などで直接開ける。

チュートリアルは「起業 → 経営 → M&A → 配置と成果 → ミニゲーム」の順に進む。目次の「はじめから遊ぶ」で通しプレイ、チャプターボタンで各画面へ直接移動できる。進行状態（コイン・建物・クエスト）は画面間で共有される。

| ハッシュ | 内容 | 対応する設計 |
|---|---|---|
| `#opening` | オープニング → 起業する会社を選ぶ | S01 |
| `#town` | 街の経営（中心画面、3D表示）：放置でコインが貯まり、タップで回収。建物をアップグレード。会社の上に企業獣が立つ。クエストで次の行動を案内 | S02, メタ進行 |
| `#deal` | M&A 7ステップ（探索・鑑定・交渉・DD・契約・統合・振り返り） | コアループ、S03〜S10 |
| `#merit` | 買収した会社を街に配置（本社の隣はシナジー×1.5）→ 成果の表示 | メタ進行、S12 |
| `#minigame` | ミニゲーム「DDスキャン」（手がかりと隣接数から3つのリスクを推理）。報酬コイン | LO-08 |
| `#shop` | 課金ポイント（課金マップ、ショップ画面） | Q-005 の検討材料 |

価格・売上構成はすべて仮置き。数値の簡略化は `docs/02_ux/learning-map.md` の簡略化メモに準ずる。

## ファイル構成

| 場所 | 内容 |
|---|---|
| `index.html` | 入口。スクリプトの読み込み順を決める |
| `css/app.css` | 全画面のスタイル（色・部品の定義） |
| `js/core.js` | 画面の切り替え、共通部品、キャラクター（SVG） |
| `js/state.js` | ゲームの進行状態、建物 |
| `js/glossary.js` | 用語モーダル。定義は `docs/glossary.md` と整合させること |
| `js/audio.js` | 効果音（Web Audio の合成音） |
| `js/kit3d.js` | 3D表示（three.js + GLB） |
| `js/screens/*.js` | 各画面 |
| `assets/models/*.glb`、`assets/models.js` | 3Dモデルと、その埋め込み版。`tools/blender/build_models.py` が生成する |
| `vendor/three.bundle.js` | three.js r170 と GLTFLoader を1ファイルにまとめたもの（MITライセンス） |
| `dev/models.html` | 3Dモデルの確認用ページ |
