# mockup

ブラウザで動くチュートリアル体験モックアップ（ADR-0002）。`index.html` をブラウザで開くだけで動く（単一ファイル、外部依存は Google Fonts のみ）。

- 画面比率：縦16:横9のスマホ縦画面を想定し、ブラウザ中央に 9:16 のステージを表示する。
- 目次（index）から、ボタンで各コンテンツを体験できる。URL の `#opening` などで直接開ける。

チュートリアルは「起業 → 経営 → M&A → 配置と成果 → ミニゲーム」の順に進む。目次の「はじめから遊ぶ」で通しプレイ、チャプターボタンで各画面へ直接移動できる。進行状態（コイン・建物・クエスト）は画面間で共有される。

| ハッシュ | 内容 | 対応する設計 |
|---|---|---|
| `#opening` | オープニング → 起業する会社を選ぶ | S01 |
| `#town` | 街の経営（中心画面）：放置でコインが貯まり、タップで回収。建物をアップグレード。会社の上に企業獣が立つ。クエストで次の行動を案内 | S02, メタ進行 |
| `#deal` | M&A 7ステップ（探索・鑑定・交渉・DD・契約・統合・振り返り） | コアループ、S03〜S10 |
| `#merit` | 買収した会社を街に配置（本社の隣はシナジー×1.5）→ 成果の表示 | メタ進行、S12 |
| `#minigame` | 頭脳ゲーム「DDスキャン」（手がかりと隣接数から3つのリスクを推理）。報酬コイン | LO-08 |
| `#breaker` | アクション「ブロックブレイク」（文字なしのカジュアルなブロック崩し、壊れない黒ブロック入り）。報酬コイン・調査チケット | メタ報酬 |
| `#shop` | 課金ポイント（課金マップ、ショップ画面） | Q-005 の検討材料 |

価格・売上構成はすべて仮置き。数値の簡略化は `docs/02_ux/learning-map.md` の簡略化メモに準ずる。

専門用語には「！」マークが付き、タップすると用語モーダル（意味・英語表記・ゲーム内での扱い）が開く。用語の定義は `docs/glossary.md` と整合させること。
