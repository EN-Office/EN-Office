# 用語集

M&A用語とゲーム内用語の**唯一の定義**。他の文書では定義を書き直さず、ここを参照する。
ゲーム内用語を追加する場合は対応する実際の概念を必ず書く。

## M&A用語

| 用語 | 英語 | 定義（簡潔に） | 関連LO |
|---|---|---|---|
| M&A | Mergers and Acquisitions | 企業の合併・買収の総称。株式や事業の取得を通じて企業の支配権を移転する取引 | LO-01 |
| 意向表明書 | Letter of Intent (LOI) | 買い手が買収の意思と主な条件（価格等）を売り手に示す書面 | LO-01 |
| 株式譲渡 | Share Transfer | 対象会社の株式を買い取ることで経営権を取得するスキーム | LO-13 |
| 基本合意書 | Memorandum of Understanding (MOU) | 本格的なDDの前に、主要条件や独占交渉権等を合意する書面 | LO-01 |
| 企業価値 | Enterprise Value (EV) | 事業が生み出す価値。株式価値に純有利子負債等を加えたもの | LO-07 |
| クロージング | Closing | 契約に基づき代金の支払いと株式等の引き渡しを実行すること | LO-01 |
| シナジー | Synergy | 統合により単独の合計以上の価値が生まれる効果（売上シナジー、コストシナジー） | LO-10 |
| 事業譲渡 | Business Transfer | 会社の事業の全部または一部を個別に譲渡するスキーム | LO-13 |
| 株式価値 | Equity Value | 株主に帰属する価値。企業価値から純有利子負債等を差し引いたもの | LO-07 |
| デューデリジェンス | Due Diligence (DD) | 買収対象の財務・法務・税務・事業・人事等のリスクと価値を調査すること | LO-08 |
| 表明保証 | Representations and Warranties | 売り手が対象会社に関する一定の事実が正しいことを契約上表明・保証するもの | LO-09 |
| 株式譲渡契約 | Share Purchase Agreement (SPA) | 株式譲渡の条件を定める最終契約 | LO-09 |
| のれん | Goodwill | 買収価格が取得した純資産の時価を上回る部分 | LO-12 |
| 減損 | Impairment | 資産の収益性が低下し、帳簿価額を回収できない場合に価値を引き下げる会計処理 | LO-12 |
| PMI | Post Merger Integration | M&A成立後の経営統合プロセス | LO-11 |
| フィナンシャル・アドバイザー | Financial Advisor (FA) | M&Aで買い手または売り手の一方に付き、助言や交渉支援を行う専門家 | LO-17 |

## ゲーム内用語

| ゲーム内用語 | 実際の概念 | 説明 |
|---|---|---|
| 企業獣（カンパニー・ビースト） | 企業 | 擬人化された企業。業種で姿が変わる |
| 鑑定 / 鑑定レンズ | バリュエーション / 評価手法 | 純資産法・類似会社比較法・DCF法の3レンズ |
| 隠しステータス | 簿外債務・偶発債務・各種リスク | DDで開示される |
| 条項カード | 契約条項 | 価格調整、表明保証、補償、前提条件など |
| なつき度 | 従業員エンゲージメント | PMIで管理する |
| 相性 | 企業文化の適合度 | 統合時の摩擦の大きさ |
| 重り | 有利子負債 | 企業価値と株式価値の差を表す |
| グループ企業価値 | 企業グループ全体の価値 | プレイヤーのスコア |
