# M&A学習ゲーム（仮称：Deal Tamers）

M&A（企業の合併・買収）の取引プロセスを、ゲームを通じて体感的に学べるアプリの企画・設計リポジトリです。
Claude Code で作業する場合は、まず [CLAUDE.md](CLAUDE.md) を読んでください。

## 現在のフェーズ
- **Phase 0：コンセプト・UX基礎設計**（現在）
- Phase 1：モックアップ制作
- Phase 2：検証（ユーザーテスト・監修）
