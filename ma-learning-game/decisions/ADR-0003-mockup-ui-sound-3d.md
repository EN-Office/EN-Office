# ADR-0003: モックアップのUI方針（ボールのミニゲーム削除・文字削減・押せる要素の明確化・サウンドと3D）

- **status**: proposed
- **起票日**: 2026-11-11
- **決定日**: —（Yuの指示 2026-11-11 に基づいて起票。PRでの承認待ち）
- **起票者**: Claude
- **承認者**: Yu

## 背景
モックアップ v0.1 に対する Yu の指示（2026-11-11、プロジェクトスレッド）：
全体のゲームフローは良い。ボールを使うミニゲームは不要になったので丸ごと外す。UIの文字を減らし、簡単な用語にはモーダルを出さない。押せるものと押せないものを明確に分ける。可能ならサウンドのインタラクションと、GLBを用いた3DのUI表現を入れる。3DモデルはBlenderで生成してよい。

## 決定
| 論点 | 決定 |
|---|---|
| ミニゲーム | ブロックブレイク（ボールのミニゲーム）を削除し、ミニゲームは「DDスキャン」だけにする。調査チケットの報酬も削除 |
| UIの規則 | `docs/03_spec/ui-guidelines.md` を新設し、全画面がこれに従う。「押せるものは立体、押せないものは平面」 |
| 用語モーダル | 専門用語（ガイドライン3.3の一覧）だけに絞る |
| サウンド | Web Audio の合成音による効果音。消音ボタンつき。BGMは未決 |
| 3D | 街の画面と主役の企業獣を three.js + GLB で表示。モデルは Blender のスクリプトで生成。3Dが使えない環境ではSVGで表示 |
| 構成 | モックアップを1ファイルから複数ファイル（css / js / assets / vendor）に分割 |

## 理由
Yu の判断による。ターゲット（シミュレーション・街づくりゲーム好き）に対して、読む量を減らし、触って気持ちのよい画面にするため。

## 影響
- `mockup/`：全画面、`mockup/README.md`
- `app/server.js`、`app/README.md`：フォルダ配信に変更
- `docs/03_spec/ui-guidelines.md`：新設
- 学習目標（learning-map）は変更なし。DDの学習（LO-08）は DDスキャンと買収フローのDDステップで扱う。
- 外部ライブラリ three.js（MITライセンス）を `mockup/vendor/` に同梱。
