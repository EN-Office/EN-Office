# ADR-0002: ターゲット・プラットフォーム・モックアップ形式・リポジトリ運用

- **status**: accepted
- **起票日**: 2026-11-04
- **決定日**: 2026-11-04（承認経路：プロジェクトスレッドでのYuの発言）
- **起票者**: Claude
- **承認者**: Yu

## 背景
Phase 1（モックアップ制作）に入る前に、OPEN_QUESTIONS の Q-001（ターゲット）、Q-002（プラットフォーム）、Q-003（モックアップ形式）、Q-009（リポジトリ構成）を決める必要があった。

## 決定
| 論点 | 決定 |
|---|---|
| ターゲット（Q-001） | 20〜50代。シミュレーションゲームが好きなユーザー、またはカジュアルな街づくり系アプリを楽しんでいるユーザー |
| プラットフォーム（Q-002） | iOS / Android のネイティブアプリ |
| モックアップ（Q-003） | ブラウザで動くもの（HTMLプロトタイプ） |
| リポジトリ（Q-009） | 当面は現在の公開リポジトリで継続 |

## 理由
Yu の判断による。Claudeの当初案（20〜30代ビジネスパーソン）より、ゲームとしての楽しさを入口にした層を狙う。

## 影響
- `docs/01_concept/concept.md` v0.3：ターゲット、街づくり要素の位置付け（ホーム演出 → メタ進行の主役）、トーン、成功指標を改訂。
- `docs/02_ux/ux-foundation.md` v0.3：前提、メタ進行（街の発展）、S02ホームの内容、オンボーディングを改訂。
- 学習目標（learning-map）は変更なし。ただし「勉強させられている感」を出さない表現が必要。
- 公開リポジトリのため、情報管理規則 10章（機密・公開範囲）を引き続き厳守する。
- ネイティブアプリの実装技術は Q-010 として新たに起票。
