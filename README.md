簡単な自己紹介
====

IT技術で世の中を面白くする、便利にするを目指すプロデューサー
~~~
業界未経験で株式会社シグナルトークへ入社。
麻雀業界の知識を元にオンライン麻雀ゲームの運営をしながら、セガ出身の代表の元でゲーム制作のノウハウを学ぶ。
さらにゲーム業界の制作管理の手法や大きな会社での制作フローを学ぶためグリー株式会社へ転職。
2年弱の中で上層部との意思決定フローの確認や制作全体の流れ、
KPI達成のためのアジャイル開発とPDCAのサイクルを学び、
概ねゲーム業界での制作業務において違いがないことを認識し、別業界へ。
XRやメタバースがコロナ禍で今後注目されうる時代が来ると信じmonoAItechnology株式会社へ転職。
メタバースイベント、OEMメタバース開発、体験型VRコンテンツ、ARコンテンツ開発を通して
Unityでの3Dデザインを活用したアプリケーションによって企業のDX支援を援助。
3DCGを活用しUnrealEngineでのコンテンツや動画制作によって車両販促支援を行うスマートエンジニアへ転職。
2025年10月より株式会社トヨタシステムズに在籍出向し、よりトヨタに近い環境で世界中のディストリビューター向けに販促支援を展開。
~~~
