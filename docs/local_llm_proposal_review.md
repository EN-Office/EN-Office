### スライド3: 最新ローカルLLM比較

| 指摘 | 修正案 |
| --- | --- |
| **Gemma 4 のサイズ表記がスライド4と不一致**。スライド3は「12B / 26B MoE」、スライド4は「Gemma 4 (31B)」 | Gemma 4 のラインナップは E2B / E4B / 12B / 26B MoE（活性約4B）/ 31B Dense。標準構成は「12B / 26B MoE」、高パフォーマンス構成は「31B Dense」と明記して両スライドを揃える |
| Gemma 4 26B MoE の必要VRAM「12〜16GB」は、4bit量子化で約15GB。コンテキスト分を含めると16GBでは余裕がない | 「12B: 約8〜10GB / 26B MoE: 約16GB（4bit量子化時）」と分けて記載し、26B MoE は16GB構成では長文ログ入力時に制約がある旨を注記 |
| **Llama 3.3 70B の「VRAM 24〜32GB」は誤り**。Q4_K_M量子化で重みだけで約42GB。24〜32GBではQ2〜IQ3クラスまで落とす必要があり、品質低下が大きい | 「70B（4bit量子化）: VRAM 約40〜48GB → GPU 2枚構成または Workstation GPU が必要」に修正。単一GPU前提なら 70B を推奨から外し、Gemma 4 31B Dense（4bit 約18〜24GB）を高精度枠にする |
| Llama 3.3（2024年12月）を「グローバル標準」と紹介しているが、Meta の最新は Llama 4 系（2025年4月〜）。「最新」を謳う資料では説明が必要 | 「Llama 4 は MoE 大型モデル（109B〜）で単体PCには不向きのため、単一GPUで動作する最新の密モデルとして Llama 3.3 70B を選定」と選定理由を補足 |
| **Codestral 22B は Mistral Non-Production License（MNPL）**。研究・テスト用途のみ許可で、商用・業務利用には Mistral との商用契約が必要。顧客納品物として不適切 | 同社の **Devstral Small 2（24B, Apache 2.0）** または **Mistral Small 3.x（24B, Apache 2.0）** に差し替え。必要VRAMは4bitで約14〜16GB（現行表記とほぼ同等） |
| 各モデルのライセンス（商用可否）が表に無い | 「ライセンス」列を追加。Gemma 4: Apache 2.0（要・公式モデルカードで最終確認）/ Llama 3.3: Llama 3.3 Community License（月間7億ユーザー未満なら商用可）/ Devstral Small 2: Apache 2.0 / Phi-4: MIT |

| 「毎秒40〜50トークン」の根拠が不明。16GB GPU（RTX 5060 Ti, 帯域448GB/s）で 12B 4bit の実測は概ね30〜45 tok/s | 「約30〜45トークン/秒（12B・4bit・RTX 5060 Ti 16GB想定）」のように条件付きで記載 |
| 「比較対照」は誤記 | 「比較対象」に修正 |

### スライド4: 推奨PC・ハードウェア構成

| 指摘 | 修正案 |
| --- | --- |
| **RTX 4070 Ti Super / RTX 4090 は生産終了済み**（2024年末）。2026年10月時点で新品の安定調達が困難 | 標準構成: 「RTX 5060 Ti 16GB または RTX 5070 Ti 16GB」。高パフォーマンス構成: 「RTX 5090 32GB」のみ、または「RTX PRO 系 Workstation GPU（48GB以上）」 |
| **高パフォーマンス構成の「70B クラスも毎秒30トークン以上」は誤り**。RTX 5090（32GB）でも 70B 4bit は収まらず、CPU オフロード時は 2〜5 tok/s 程度 | 推奨対象を「Gemma 4 31B Dense / Devstral Small 2 24B（いずれも4bitでVRAM内に収まる）」に変更し、「約25〜40トークン/秒」に修正。70B を残す場合は GPU 2枚（例: RTX 5090 ×2）または 48GB クラスの Workstation GPU を明記 |
| RTX 5090 の国内実勢価格は 2026年に高騰（最安でも約60万円、平均70万円超との報道あり） | 高パフォーマンス構成の見積に反映（スライド6参照）。調達リスクとして「価格・納期は発注時点で再見積」と注記 |
| 「Intel Core i7（第14世代以降）」は現行の Intel 製品名が Core Ultra 200S 系に移行しており表記が古い。また第13/14世代は安定性問題（劣化不具合）が報告された世代 | 「Intel Core Ultra 7（200S系）または AMD Ryzen 7 9000系」に更新 |
| 「レスポンス遅延ゼロ」は過大表現（初回のモデルロードやプロンプト処理には数秒かかる） | 「体感上ストレスのない応答速度」程度に緩める |
| セキュリティルーム仕様「BIOSレベルでWi-Fi/Bluetooth/カメラ無効化」と、スライド5の「ネットワークカード物理無効化」が揃っていない | どちらかに統一。推奨は「無線モジュール物理撤去 + 有線LANはBIOS無効化 + USBポート制御（デバイス制御ソフトまたは物理封止）」まで書くと説得力が増す |
| 電源容量（RTX 5090 はTDP 575W、電源850W〜1000W推奨）の記載が無い | 「電源ユニット: 標準 750W / 高パフォーマンス 1000W以上（80PLUS Gold以上）」を追加 |

### スライド7: 本提案の優位性と期待効果

| 指摘 | 修正案 |
| --- | --- |
| 「運用ランニングコストゼロ」は誤解を招く。電気代（高パフォーマンス構成はフル稼働時約600〜800W）、ハードウェア故障時の交換、モデル更新作業は発生する | 「API従量課金・月額サブスクリプション費用ゼロ」に限定して記載し、「電気代・保守費を除く」と注記 |

## 修正後の推奨モデル構成（案）

| 用途 | モデル | ライセンス | 4bit時VRAM目安 | 対応構成 |
| --- | --- | --- | --- | --- |
| 第一推奨（日本語ログ解析） | Gemma 4 12B | Apache 2.0（要確認） | 約8〜10GB | 標準 |
| 第一推奨（高速・MoE） | Gemma 4 26B A4B | Apache 2.0（要確認） | 約16GB | 標準（長文時は高パフォーマンス推奨） |
| 高精度 | Gemma 4 31B Dense | Apache 2.0（要確認） | 約18〜24GB | 高パフォーマンス |
| コード・修正案生成 | Devstral Small 2 24B | Apache 2.0 | 約14〜16GB | 標準/高パフォーマンス |
| 論理推論（英語中心） | Phi-4 14B | MIT | 約9〜10GB | 標準 |

Llama 3.3 70B は「GPU 2枚構成または 48GB クラス Workstation GPU を追加する場合のオプション」として脚注に落とすのが安全です。
